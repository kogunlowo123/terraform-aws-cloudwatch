Architecture Document — Comprehensive AWS CloudWatch Observability Module

Executive Summary

Terraform module for comprehensive AWS CloudWatch observability including log groups, metric alarms, composite alarms, dashboards, anomaly detection, Synthetics canaries, Contributor Insights, metric streams, and cross-account observability. The module provides a unified interface to deploy and manage the full CloudWatch observability stack through a single, composable Terraform module with support for OAM sinks and links for centralized multi-account monitoring.

Data Flow

1
Application metrics and logs flow into CloudWatch Log Groups with configurable retention and KMS encryption.
2
Metric Alarms evaluate metrics against thresholds (standard) or math expressions, triggering SNS notifications.
3
Composite Alarms combine multiple metric alarms with logical AND/OR/NOT operators for complex alerting.
4
Anomaly Detection learns metric patterns and creates anomaly band alarms for drift detection.
5
Synthetics Canaries continuously probe endpoints and store artifacts in S3, alerting on failures.
6
Metric Streams export real-time metrics via Kinesis Firehose to external monitoring systems (Datadog, Splunk, etc.).
7
OAM Sinks and Links enable cross-account observability by sharing metrics, logs, and traces between AWS accounts.

Security Controls

KMS Encryption for Log Groups

Log groups support customer-managed KMS key encryption via kms_key_id for data at rest protection.

OAM Sink Access Policy

Cross-account sink policies restrict access to specified source accounts or organization IDs using IAM condition keys.

Canary VPC Isolation

Synthetics canaries support VPC configuration with private subnets and security groups for isolated endpoint testing.

IAM Role Scoping

Metric streams and canaries require explicit IAM role ARNs, enforcing least-privilege access patterns.

Industry Adaptation

Healthcare

HIPAA-compliant log retention with KMS encryption. Anomaly detection on patient system availability. Synthetics canaries for EHR endpoint health.

Finance

Real-time metric streaming to SIEM. Composite alarms for multi-signal fraud detection. Cross-account observability across trading and settlement accounts.

Government

FedRAMP-aligned log group encryption with GovCloud KMS keys. Contributor Insights for access pattern auditing. OAM for centralized agency monitoring.

Retail

Synthetics canaries for checkout flow monitoring. Anomaly detection on order processing metrics. Dashboard visualization for seasonal traffic patterns.

SaaS

Multi-tenant metric streams to observability platforms. Per-customer composite alarms for SLA monitoring. Cross-account OAM for shared infrastructure visibility.

Production Readiness Checklist

  • Enable KMS encryption on all log groups storing sensitive data
  • Set appropriate log retention periods (30-365 days based on compliance needs)
  • Configure alarm actions to SNS topics with appropriate subscription protocols
  • Set up composite alarms to reduce alert fatigue from correlated metric alarms
  • Deploy Synthetics canaries for critical API and UI endpoint monitoring
  • Enable anomaly detection for baseline metrics that may drift unpredictably
  • Configure metric streams for external observability platform integration
  • Set up cross-account OAM for centralized multi-account monitoring
  • Apply consistent tags across all resources for cost allocation and governance
  • Review and restrict OAM sink policies to specific source accounts
